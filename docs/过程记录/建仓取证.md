# 仓库创建取证与 MCP 建仓说明（2026-11-12）

## 什么是「MCP 建仓」

MCP（Model Context Protocol）是 AI 助手连接外部工具的标准协议。「GitHub MCP 建仓」指学生在 AI 会话里**通过 GitHub MCP 工具**（如 `create_repository`）创建远程仓库，留下工具名、请求参数、返回结果（仓库 URL、时间）的完整证据链，作为「AI 协同创建交付仓库」的过程证据——与用网页手工点“New repository”相对。
