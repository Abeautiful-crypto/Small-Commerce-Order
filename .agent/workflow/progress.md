# 功能点进度追踪（progress.md）

> 本表是**人读总览**；"已通过"的唯一有效证据是 `.agent/workflow/gate-records/<ID>.json` 中 `result == PASS`。
> AI 每次闸门通过后更新本表状态与证据时间；闸门失败时状态保持"闸门失败"，不得改成"已通过"。
> 状态机与判定规则见 `general/feature-gate.md`，功能点定义见 `feature-points.md` / `features.json`。

## 状态取值

`未开始` → `开发中` → `待验证` →（`闸门失败` → `待验证` 循环）→ `已通过`

## 纪律

- 一次只改一行状态；改状态前先确认对应 gate-record 存在且为 `PASS`。
- 证据文件由脚本生成，**不要手改**；手改证据等同于伪造测试通过（违反 `principles.md` 第 2 节）。
- `未开始` 直接跳到 `已通过`、或 `闸门失败` 期间推进别的阶段，均为违规。
