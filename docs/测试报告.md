## 4. 五大场景一键验收（2026-11-12，memory 存储干净状态）

- S1 正常成交 13/13；S2 缺货弃单+并发 6/6；S3 售前退款 9/9；S4 迟到支付 11/11；S5 操作异常 9/9。
- HARD_ERROR 扫描：oversell / duplicate_charge / duplicate_release / unauthorized 全部 NONE。
- 历史缺陷修复回归：本报告版本前，默认演示模式（memory + Redis）下「下单后可售数量不刷新」曾导致 S1 的 `stock_occupied_on_order` 等 7 项失败；修复 memory 存储写失效后 48/48 通过（见 `.agent/general/issue-log.md` 2026-11-12 条目）。
